# EML-SICKEL — executable roadmap add-on

**Status (9 November 2026):** Real-data audit, cutoff experiments, within-plot panel comparisons, two-direction year-transfer checks, model freeze, and the **single reserved day-45 validation** are complete. The numerical results and one-attempt guardrail records are saved under `outputs/roadmap/` (ignored by Git). Source code, tests, this execution guide, and non-identifying aggregate CSVs under `results/` may be shared. No row-level yield labels, scene files, notebooks, or scientific report are included in Git.

The add-on has been applied to the local repository without overwriting existing experiments. The instructions below remain available for reproduction. Do not treat the official validation set as a hyperparameter-selection dataset.

## Prerequisites

The existing project must already have these two files, generated by its upstream feature pipeline:

- `outputs/features/full_stage_features.csv` (319 plot-seasons; 282 official TRAIN and 37 official VAL; plot-disjoint)
- `outputs/features/full_observation_features.csv` (scene-level records, with real `image_date`, `status` and S1/S2 spectral features)

The program deliberately checks the known dataset size and plot counts. If the dataset has legitimately changed, inspect and document the difference rather than silently overriding its assertions. It uses the repo's existing dependencies (`numpy`, `pandas`, `scikit-learn`); scikit-learn >=1.4 is recommended.

## Observed results from the one-time evaluation (9 November 2026)

The fixed primary horizon is **45 days after sowing**. The full training cohort contains 282 plot-season records from 117 plots; the reserved comparison uses 37 records from 14 entirely different physical plots. All reported errors below are in **kg/acre**.

| Frozen model | TRAIN plot-grouped CV RMSE, day 45 | Official reserved VAL RMSE | VAL MAE | VAL R² |
| --- | ---: | ---: | ---: | ---: |
| Agronomic Ridge | 351.18 | 533.23 | 337.53 | 0.278 |
| PCA + Ridge, S1/S2 | 346.93 | 548.13 | 354.89 | 0.238 |
| Partially penalized Elastic Net, S1/S2 | 355.26 | 534.40 | 342.84 | 0.275 |
| Extra Trees, agronomic controls only | 314.78 | **505.30** | **311.28** | **0.352** |

**Primary predeclared contrast:** PCA + Ridge *worsened* validation RMSE by 14.90 relative to agronomic Ridge. A descriptive paired bootstrap of the same fixed validation predictions, resampling 14 physical plots 4,000 times, gave a 95% interval of **−23.26 to −4.13 kg/acre** for the PCA improvement (Ridge RMSE minus PCA RMSE). Extra Trees improved on Ridge by 27.93, but its corresponding interval of **−29.61 to 101.34** includes zero. These intervals do not account for fitting uncertainty, repeated historical experimentation, or multiple model comparisons.

**Interpretation:** Satellite features offered modest exploratory within-year gains, but **no consistent generalization benefit** in year-transfer or the official reserved comparison. The within-plot difference test matched 64 crop-season pairs from 60 physical plots; satellite Ridge (276.46 RMSE) did not beat the mean-change baseline (274.60). The validation error scale is considerably higher than within-TRAIN CV. Do not tune further on this official VAL cohort.

**Public aggregate outputs (no row-level labels):** `results/roadmap_aggregate_metrics.csv` combines 30 cutoff-CV, 20 transfer, four reserved-validation, and two panel-comparison rows. `results/validation_paired_differences.csv` records the fixed-prediction paired plot-bootstrap differences. Detailed held-out predictions, freeze hashes and labels are kept locally under ignored `outputs/roadmap/`.

**Audit trail:** The initial frozen manifest was blocked by a pre-scoring guardrail type mismatch (Python tuple vs JSON list for model names). **No validation labels were read or scored in that failed attempt.** The code was corrected to compare the same ordered model names, a regression test was added, and the only amended frozen field was the source-code SHA256. The original frozen manifest and explanation are preserved locally as `04_frozen_manifest_before_preflight_fix.json` and `04_prevalidation_preflight_correction.json`. The fixed day, model list, data hashes, hyperparameter grids and results remained unchanged. One reserved comparison was then completed and locked by `05_validation_attempted.json`.

### Exactly what is modeled

At each cutoff, only scenes with `status == 'ok'`, sensor `S1` or `S2`, and acquisition dates between the sowing date and sowing date + cutoff are accepted. Eight predetermined sensor indices have fold-independent **median** and **latest** summaries (16 inputs). No actual harvesting date or retrospective relative-season fraction is a predictor. Harvest dates serve only to establish that the forecast time precedes harvest. The all-cutoff comparison uses the common day-90-eligible cohort.

Five fixed models are compared: agronomic-controls Ridge; Ridge + S1/S2; PCA + Ridge on S1/S2; partially penalized Elastic Net on S1/S2 (agronomic controls unpenalized by Frisch-Waugh-Lovell residualization); and controls-only Extra Trees. The last model is a **non-EML benchmark**. All preprocessing, PCA, regularization, and hyperparameter searches happen inside training folds. All results use grouped outer 5-fold / grouped inner 3-fold CV.

The main test is **day 45**. Other cutoffs are descriptive, avoiding selecting a cutoff solely because it happened to be best on the explored training data.

### Panel limitations

Pairs must have the same physical `plot_id`, comparable `season`, same reported `variety`, an unambiguous single record per plot-season-year, and a sow-date difference of at most 45 days on a circular annual calendar. Paired observations that fail these checks are excluded without inspecting their yields. If at least 30 independent matched plots remain, the script fits an exploratory Ridge model to first differences in a few satellite indices using plot-grouped CV; otherwise it saves only descriptive matching statistics. This is **not causal identification** and is not the same prediction task as new-plot yield forecasting.

### Explicit limitations

- **Yield unit:** The original SICKLE WACV 2024 supplementary paper, Figure 4d, labels field yield **kg/acre**, and plot area **acre**. Citation: https://openaccess.thecvf.com/content/WACV2024/supplemental/Sani_SICKLE_A_Multi-Sensor_WACV_2024_supplemental.pdf. Do not convert the original numeric labels without checking the released dataset.
- SICKLE yield labels were collected through farmer recall; they are not directly measured harvest weights.
- The 282 training plot-season labels and only two years limit generalization; models have been explored on TRAIN in earlier project phases.
- Previous work examined the official VAL for an earlier Ridge setting. Thus final validation is **not a pristine independent holdout**, even with a frozen model list.
- Bootstrap bounds in the cutoff evaluation condition on fixed OOF predictions, do not refit models, and are not multiple-test adjusted.
- Pixel-mask spatial alignment, scene QA interpretation, and raw-label provenance also require running the **existing repository tests** with its complete original satellite dataset. This add-on does not reprocess original georeferenced pixels or silently substitute a new extraction method.
